# Marca ConectaPro — carril ligero

ConectaPro continúa exclusivamente como fork de Vocero CRM. Se adapta la marca, sin importar código ni planes del prototipo anterior.

## Aceptación
- La marca predeterminada es ConectaPro; acceso, título, favicon y app instalable usan ese nombre y su inicial C.
- Los textos operativos usan «el CRM» cuando corresponda para respetar la personalización por negocio.
- Se conserva la licencia MIT y el copyright original. El README identifica autor, repositorio original y naturaleza del fork.
- La marca personalizada y los logos subidos siguen teniendo prioridad; no se reescriben datos existentes.
- Se conservan integraciones, contratos, identificadores internos, estilos y funciones heredadas.

## Alcance
No se incorporan cambios SaaS, afiliación, pagos ni despliegue. El distintivo C utiliza el soporte white-label ya existente. No se renombra la API ni se reemplazan los identificadores internos Vocero, para facilitar sincronización con upstream.

## Verificación
Comprobación de tipos, lint, pruebas, build y revisión del acceso y recursos de marca en una instancia local sin credenciales reales.
